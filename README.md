# Assignment 01 - Java Character CLI

Java 상속 관계를 연습하고 기초문법을 공부하기 위해 만든 간단한 캐릭터 생성 CLI 프로그램입니다.

## 프로젝트 개요

이 프로그램은 사용자가 이름, 나이, 레벨을 입력하고 종족을 선택하면  
선택한 종족에 맞는 전사 캐릭터를 생성하고 최종 캐릭터 정보를 출력하는 콘솔 프로그램입니다.

## 클래스 구조

```text
[GameCharacter]
--------------------------------
- name
- age
- level
- hp
--------------------------------
+ showStatus()
+ move()

        ↓ 상속                  ↓ 상속

[Human]                         [Orc]
-------------------------------- --------------------------------
- intelligence                  - rage
-------------------------------- --------------------------------
+ runAway()                     + smash()

        ↓ 상속                  ↓ 상속

[HumanWarrior]                  [OrcWarrior]
-------------------------------- --------------------------------
- attackPower                   - attackPower
-------------------------------- --------------------------------
+ slash()                       + slash()
